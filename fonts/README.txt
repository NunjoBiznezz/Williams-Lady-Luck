Fonts for Lady Luck artwork (free Google Fonts, SIL Open Font License)

Used on card_value_when_lit_clean.png:
  CARD VALUE  - Archivo Black            (archivo-black-400.ttf)
  WHEN LIT    - Oswald SemiBold, letter spacing ~6%   (oswald-600.ttf)
  100         - League Gothic, slightly thinned       (league-gothic-400.ttf)

Also here for other lettering: Oswald 200-700, Archivo Narrow 400-700, Francois One.
Install on the Mac: double-click a .ttf and click Install (Font Book), then restart GIMP/Inkscape.

Added 2026-11-23:
  archivo-semicondensed-800.ttf - Archivo SemiCondensed ExtraBold (static instance of Google's
  variable Archivo, wdth 87.5 / wght 800; licence archivo-OFL.txt). Used for ADVANCE / CARD on
  CC advance card hex.svg - matches the original letter widths and weight much better than Archivo Black.
